# Router Convention

## Route Modules

All routes are manually registered under `src/router/modules/`:

- `public.routes.js`: public pages
- `user.routes.js`: authenticated user pages
- `admin.routes.js`: admin/layout pages
- `test.routes.js`: temporary or testing pages

Single registration source: `src/router/index.js`.

## Meta Schema

Every route uses unified `meta` generated by `withRouteMeta`:

- `requiresAuth`: whether login is required
- `requiresAdmin`: whether admin role is required
- `title`: page title segment
- `layout`: layout tag (`public` / `auth` / `default`)
- `hidden`: hide from menu or navigation builders

## Startup Order

`src/main.js` fixed boot sequence:

1. create app + pinia
2. read local auth state
3. validate auth token and fetch `/auth/me`
4. install route guards
5. mount router and app

This avoids initial auth flicker and inconsistent first navigation.
