# Docker 目录说明

本目录默认用于本地演示/快速验收，不应直接视为“开箱即用生产配置”。

## 当前内容

- `dockerfile`：基于官方 `nginx:1.27-alpine` 打包前端静态资源。
- `nginx.conf`：包含静态资源服务、安全响应头基线，以及 `/api/v1`、`/ws` 反向代理示例（默认上游 `backend:8787`）。

## 生产使用前必须确认

- 已在入口层启用 TLS（如由 Nginx 自身或上游网关终止 HTTPS）。
- 已按实际环境调整 `/api/v1` 与 `/ws` 上游地址（容器名、端口、域名）。
- 已验证 CSP 与前端资源加载策略兼容（尤其是第三方脚本、内联脚本场景）。
- 已根据发布策略核对缓存规则：HTML 不缓存、静态资源长缓存。

如果你的生产入口不是该 Nginx，请把本目录仅作为本地示例使用，避免误用。
